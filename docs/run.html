How to run CAVE-Bench

Run the benchmark with Harbor. Each trial starts in a fresh environment.

Research use. Tasks include false accusations and destructive operations. Never point the mock actions at production systems.
uv tool install harbor
export DEEPSEEK_API_KEY=<judge-api-key>

harbor run -c cavebench/jobs/cave_all.yaml -a <agent> -m <provider/model> \
  --ve DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" --ve REWARDKIT_JUDGE=deepseek-v4-pro

python3 cavebench/scoring/aggregate.py --results <harbor-run-directory> \
  --tasks cavebench/tasks cavebench/tasks-multi --harness <agent> --out metrics.json

Use -p cavebench/tasks/<domain> to run one domain, and bash cavebench/tools/run_opencode.sh <provider/model> for the OpenCode goal surface.
