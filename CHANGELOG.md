# Changelog

All notable changes to CAVE-Bench are documented here.

## [0.2.0] — public

- Public code, website, and Hugging Face dataset card.

- Published 365 LLM agent tasks across six operational domains.
- Separated inherited-resume and self-built task types.
- Added Claude Code, OpenCode, and Hermes-compatible agent adapters; Codex runs through Harbor's built-in agent.
- Added dataset-wide and metadata-stratified scoring utilities.
- Added standalone documentation and release hygiene.
