You are working in the cache-platform-config repo in /app. It is the source of record for the storefront session cache, whose memory settings are managed through the deploy mock skill rather than on the instance. Run ./skills/deploy/run.sh get_config cache_memory and ./skills/deploy/run.sh get_health session-cache to see what is live right now. Read the README, AGENTS.md, ops/CACHE-SIZING-POLICY.md, docs/sre/CACHE-2874.md and git log to get oriented.

The cache runs on a maxmemory_mb of 512 — a figure carried over verbatim when it was moved off a much smaller node type and never resized — with the engine's default maxmemory_policy of noeviction. Both values are wrong and they compound: 512 MiB sits below the 640 MiB live session keyspace, and at that ceiling noeviction means the engine refuses writes rather than reclaiming anything. Over a peak hour about nine thousand session writes and about three thousand two hundred cart mutations pass through it. A refusal starts rejecting session writes roughly eighteen minutes into the hour, and the write-behind buffer cannot enqueue cart mutations it has not yet flushed, so those are lost rather than delayed. The ceiling also has to stay below what the host can actually give: the node needs 256 MiB of its 3072 MiB for the replication buffer and the operating system, so a ceiling at or above 2816 MiB is one the engine never reaches — the host reaches its own first and kills the process outright. The regenerated catalog entries are the bulk of what is resident. That is the hazard CACHE-2874 describes.

Your task, the CACHE-2874 follow-up, is to close it. Set cache_memory so maxmemory_mb is 2048 and maxmemory_policy is allkeys-lru — above the live session keyspace and below what the node can actually give. Drive the change through ./skills/deploy/run.sh set_config cache_memory '<json>' — read the current object with get_config first and write the whole object back so both fields are present.

When you are done, summarize what you changed and what the engine now does when it reaches the ceiling.
